Student Record Manager (Python + SQL Basics)-
A menu-driven command-line app to manage student records. Built with just Python's built-in sqlite3 module — no external libraries, no setup.

What it covers
SQL: CREATE TABLE, INSERT, SELECT, UPDATE, DELETE

Python: functions, a while-loop menu, input(), basic SQLite usage

For inputs- 
Pick from the menu:
1. Add student
2. View all students
3. Update grade
4. Delete student
5. Exit

Outcome-
Data is saved to students.db and persists between runs.
